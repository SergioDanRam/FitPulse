# FitPulse

FitPulse es una aplicación para gestión de entrenamientos, compuesta por un backend en **NestJS** y un frontend en **Next.js**.

## Estructura del proyecto

```
FitPulse/
├── backend/     # API REST (NestJS + TypeORM + PostgreSQL)
└── frontend/    # Aplicación web (Next.js)
```
## Estado del proyecto

Proyecto en desarrollo activo (MVP). La documentación funcional del producto se mantiene fuera del repositorio.
